# 05｜课程检索、问答和评测

[本地 tracker 与执行约定](development.md) · [字段字典](database.md) · [接口契约](interfaces.md)

## Problem Statement

学生需要知道答案来自哪份讲义或哪段代码；检索还要遵循教师材料的访问范围。

## Solution

学⑧、师⑨问答和独⑥共享回答、可定位引用及资料不足状态。先让文本和代码有据可查，再处理三类视觉材料。

## User Stories

1. 作为学生，我希望询问概念、原理、代码和调参，以便获得合适层次的解释。
2. 作为教师，我希望从引用回到一个章节、函数或 notebook 单元格，以便核对依据。
3. 作为学生，我希望在资料不足时得到明确反馈，以便知道还缺哪类材料。
4. 作为课程维护者，我希望在同一题集比较关键词和向量检索，以便找出检索和回答分别错在哪里。
5. 作为师生，我希望查看普通图片、标注图和训练曲线的有依据解释，以便把观察与课程知识联系起来。

## Implementation Decisions

- 讲义按章和知识点再按段，代码按类/函数，习题与答案分开，notebook 保留单元格顺序。片段继承材料权限与案例版本。
- 采用 Sentence-Transformers 生成嵌入、pgvector 余弦距离取前三；先筛版本与权限。索引记录模型标识及版本；模型或材料变更只重建受影响索引。
- 生成器读取已授权片段并输出 Q1；教师/学生两种检索范围共用同一机制。视觉理解用获准模型与文件；无依据记录独立状态。
- 对接范围：Q1 → C1、F1、E1；chunks。

## Testing Decisions

先用自制、带标准位置的数据检查 Q1，再用真实标注题比较关键词/向量的 top-3 命中数和答案获材料支持的比例。无依据题逐题核对；三类图分别留输入与判断依据。

## Out of Scope

| 本模块范围外 |
|---|
| 将教师答案纳入学生检索范围、无授权模型外发 |

## Further Notes

评测集讲义/代码/习题/无依据每类至少 5 题；命中率目标 ≥80%。真实资源由 5 号对接。
