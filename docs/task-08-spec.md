# 08｜学情分析与教师周报

[本地 tracker 与执行约定](development.md) · [字段字典](database.md) · [接口契约](interfaces.md)

## Problem Statement

高频提问、提交次数和完成率使用不同分母；学生重交或服务重试都容易让数字失真。

## Solution

师⑧与独⑧从同一授权快照读取指标并生成周报，能从原始记录复算每一个数字。

## User Stories

1. 作为教师，我希望看到应交数和已交数，以便解释班级完成率。
2. 作为教师，我希望按时间看高频知识点、运行情况和成绩分布，以便安排下一周讲解。
3. 作为教师，我希望在相同区间生成周报，以便复用图表口径。
4. 作为模块调用者，我希望重发同一事件后看到已接收，以便避免高频问题重复计数。
5. 作为平台管理员，我希望只读取被授权的班级统计，以便按职责管理数据。

## Implementation Decisions

- E1 使用生产方生成的 event_id 去重；同号异载荷报冲突。高频问题只数 5 号事件，未分类单列，同数按标签排序。
- Asia/Shanghai，[from,to)；任务按发布时间入区间，分母为实验任务的发布快照人数对，分子按学生－任务对去重，取 min(to,as_of) 前的提交。运行按结束时间，成功数除以全部终态数。
- 趋势按周一分周；所选任务最新提交的已批成绩分 <60、60–<80、80–<90、90–100。周报带相同 as_of、范围和建议；无分母返回 null。
- 对接范围：E1/E2/E3 → 授权班级、应交快照、提交、成绩、运行；learning_events。

## Testing Decisions

手算 4 名学生、2 人提交、1 人重交得到 2/4；模拟事件重放及周一切换。对照同一班级的 E2 和 E3，换教师账号验证范围。

## Out of Scope

| 本模块范围外 |
|---|
| 用活跃度推断个人掌握程度、采集学生原代码或原问题 |
