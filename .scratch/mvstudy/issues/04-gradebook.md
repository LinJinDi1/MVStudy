# 04 — 用四人班级展示批改名单

**Parent:** [4 号 Spec](../../../docs/task-04-spec.md) · [共享契约与关闭规则](../../../docs/development.md)

**What to build:** 用固定提交快照实现教师批改名单与版本选择；从一行进入评审时携带该行的提交及文件编号。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 四人中分别展示 missing、pending、graded（含 0 分）；重新提交后高亮最新版本。
- [ ] 从旧版本进入评审仍传旧 submission_id/file_id，保存评分时保留当前选择。
