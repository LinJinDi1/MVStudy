# 08 — 用已知班级数据生成可复算的周报

**Parent:** [8 号 Spec](../../../docs/task-08-spec.md) · [共享契约与关闭规则](../../../docs/development.md)

**What to build:** 向同一统计入口输入两班的固定数据，生成教师图表与周报，供后续替换数据来源。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 4 人应交，2 人提交、其中 1 人重交：结果为 2/4；零分母显示暂无数据。
- [ ] 周一跨周、问答事件重放、0 分和未批各有样例；更换班级后汇总与周报同时切换。
